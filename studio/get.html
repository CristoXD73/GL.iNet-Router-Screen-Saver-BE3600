GL.iNet Router Screen SaverGL-BE3600 (Slate 7)

Put the screen saver on your router

Use a computer that is on your router’s Wi-Fi (or plugged into it). You will need the router’s admin password — the one for its admin web page.

Install Uninstall

    Install: Windows · Mac · Linux
    Uninstall: Windows · Mac · Linux

    1. It finds your routerThe address that worked last time, then this computer’s router, then GL.iNet’s usual 192.168.8.1. If yours is somewhere else, it asks you to type the address.
    2. You type the router’s admin passwordInto that window only, never a web page. Nothing shows while you type; that’s normal. Say yes to Save this login and you won’t need it next time.
    3. It installs, and says when it’s doneTwo eyes wake up on the router’s screen while its fan revs. After a few idle seconds the screen shows the animation. Uninstall puts GL.iNet’s normal screen back and removes everything, from the router and from this computer.
    Advanced

    Design your own animations: Studio Link

    Studio Link installs the screen saver too, then opens Motion Studio already connected to your router, so what you design goes straight onto it. Windows · Mac / Linux (run it with python3 studio-link.py).

    From the project files

    On GitHub: Code → Download ZIP (or clone it), then Install.cmd (Windows), Install.command (Mac) or ./install.sh. The Install and Uninstall files above are the same as python3 tools/studio_link.py --install / --uninstall, or tools\studio-link.ps1 -Install / -Uninstall on Windows.

    Uninstall on the router itself

    Connect with ssh root@192.168.8.1 (your router’s address, and its admin password), then type be3600-uninstall --purge.

    Check a download

    Every file is listed with its checksum in SHA256SUMS; how it all works is in the README.

    Your password is typed into the program’s own window, never into a web page, and is never saved; a saved login is a key locked by your computer’s keychain. Just want a look first? Open Motion Studio or Fan Studio.
