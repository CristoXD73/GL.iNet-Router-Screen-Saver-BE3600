GL.iNet Router Screen SaverGL-BE3600 (Slate 7)

Start here: get Studio Link

One file. It sets up the router, then opens Motion Studio already connected to it — so this is the only thing you need to download.

WindowsStudio-Link.cmd Mac / Linuxstudio-link.py
  1. Double-click itWindows may warn about a downloaded file: choose Keep, then Run anyway. Mac and Linux: python3 studio-link.py.
  2. Type the router's admin password onceInto that window, never into a web page. Press Enter to let it install the screen saver, and Enter again to remember this computer so it never asks again.
  3. It finishes with the eyes and a revTwo eyes wake up on the router's front screen while the cooling fan revs under them. That is how you know it worked.
  4. Motion Studio opens, connectedDesign an animation and press Compile; it goes straight onto the router.

Studio Link listens on this computer only, and your password never touches a web page — how it works, checksums.
Just want a look first? Open Motion Studio or Fan Studio — both work without it.
